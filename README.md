# Leafy 2026

하루의 작은 계획을 기록하고 관리할 수 있는 **2026년 달력 투두 리스트 웹 서비스**입니다.

초록색 단색 팔레트와 떠다니는 나뭇잎 이모지를 활용해 편안하고 자연스러운 분위기로 디자인했습니다. 별도의 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

## 주요 기능

- 2026년 1월부터 12월까지 월별 달력 탐색
- 원하는 날짜를 선택해 할 일 추가
- 할 일 완료 상태 변경 및 개별 삭제
- 선택한 날짜의 완료 항목 일괄 정리
- 할 일이 있는 날짜에 표시와 개수 제공
- 현재 월의 전체 할 일 완료율 표시
- 브라우저 `localStorage`를 이용한 자동 저장
- 데스크톱과 모바일을 지원하는 반응형 레이아웃
- 움직임 감소 설정을 고려한 접근성 지원

## 디자인 특징

- Pretendard 웹 폰트 사용
- 초록색 중심의 단색 컬러 시스템
- 그라데이션 미사용
- 별도의 SVG 이미지 미사용
- 배경에 나뭇잎 이모지 애니메이션 적용
- 날짜 및 버튼에 접근성 라벨 제공

## 실행 방법

별도의 빌드 과정이 필요하지 않습니다.

1. 프로젝트 폴더에서 `index.html`을 브라우저로 엽니다.
2. 달력에서 날짜를 선택합니다.
3. 입력창에 할 일을 작성하고 `+` 버튼을 누릅니다.

로컬 서버로 실행하려면 다음 명령어를 사용할 수 있습니다.

```bash
python3 -m http.server 4173
```

이후 브라우저에서 `http://localhost:4173`에 접속합니다.

## 파일 구조

```text
.
├── index.html    # 서비스 화면 구조
├── styles.css    # 디자인 및 반응형 스타일
├── script.js     # 달력 생성과 투두 관리 기능
└── README.md     # 프로젝트 소개 문서
```

## 데이터 저장

할 일 데이터는 사용 중인 브라우저의 `localStorage`에 `leafy-2026-todos`라는 키로 저장됩니다.

- 페이지를 새로고침하거나 브라우저를 다시 열어도 기록이 유지됩니다.
- 다른 브라우저나 기기와 자동으로 동기화되지는 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 저장된 할 일도 함께 삭제될 수 있습니다.
